user-modified vanilla interfaces (12, 121, 160, 161, 164, 192, 205, 215, 218, 465, 476, 548, 621, 629) and
clientscripts (37 205 336 342 393 414 423 426 687 699 701 702 912 1074 1090 1092 1261 1311 1448 1705 2066 2094 2096
2186 2200 2735 3178 3310 4073 4104 6138), the UI step stores the merged 241 group here with a note saying what was
re-applied. It also stores the 211 -> 241 component remap TSV. The UI area owns the file layout.
