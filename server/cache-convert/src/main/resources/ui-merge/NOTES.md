# UI merge: GadScape's edits of vanilla interfaces and clientscripts on build 241

Generated by `UiMergeMain gen` (package `com.gadscape.cacheconv.uimerge`) from BASE (openrs2 2746), USER (GadScape's 211 cache) and
VAN211, using the decisions in `UiMergeSpecs` (interfaces) and `ScriptRecipes` (scripts). Do not edit the data files by hand:
change the specs and regenerate; `UiMergeMain check` fails when the stored data no longer matches a regeneration.

## How it works

- **What the user changed** is VAN211 -> USER. Each of the 14 interfaces and 31 scripts gets one decision:
  - **merged**: the edit is re-applied onto BASE's version. Interfaces: field by field (`IfMerge`), on the BASE component the
    211 -> 241 remap names (server docs table checked against BASE's gamevals names, spell-obj anchors for 218, content alignment,
    and hand overrides where the table is wrong); a field BASE changed too goes to USER for content and to BASE for layout (logged).
    Components the user added are appended after BASE's last one. Scripts: an anchored recipe inserts GadScape's instructions into
    BASE's body (jumps and switches keep their targets; BASE's signature is kept).
  - **user**: BASE never changed the id since 211, so USER's version is taken (converted to 241).
  - **base**: BASE's version is kept; the reason says why nothing (or not everything) of the user's edit is needed.
- **Data**: `interfaces/ID.if` (component bytes in hex + the USER-sourced references), `scripts/ID.cs2` (text assembly; `u` marks
  GadScape's lines, `@kind` their id operands), `manifest.tsv` (decision + SHA-256 of the BASE group the merge was made against).
- **Build** (`UiMergeStep`, step `ui-merge`): refuses an entry whose BASE group changed, maps GadScape's references through the
  id map (custom scripts, sprites, vars, configs and interfaces relocated by earlier steps), writes the groups. BASE's own code is
  never remapped.
- **component-remap.tsv**: 211 -> 241 component ids for every vanilla interface the server references (plus the docs table's),
  keyed by the USER (GadScape 211) numbering the server uses; ui-convert reads it in place of the docs table.
